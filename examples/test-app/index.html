🌐 Official OpenID Foundation (OIDF) Conformance Suite Instructions

How to submit SaaSKit for official OpenID Connect Certification.

  1. Hosted Test Suite: Visit www.certification.openid.net and sign in with your OpenID credentials.
  2. Local Docker Conformance Runner: Alternatively, run the official OIDF test runner locally: 
    docker run -p 8443:8443 -docker-registry.openid.net/oidf/conformance-suite:latest
  3. Configuration Profile: Select Basic OP or Configurable OP test profile. Set Discovery URL to http://localhost:8080/.well-known/openid-configuration.
  4. Key Algorithms: SaaSKit currently uses asymmetric signing (RS256 default, supporting ES256 & EdDSA).
